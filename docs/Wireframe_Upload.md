# 🖼️ 와이어프레임 1: 영상 업로드 및 설정 (Upload View)

사용자가 분석할 투구 영상을 업로드하고 필요한 메타데이터를 입력하는 첫 번째 화면입니다.

## 1. 화면 레이아웃 (Screen Layout)

```text
+---------------------------------------------------------+
|  [로고] Pitch-Command-AI                    [로그인/설정] |
+---------------------------------------------------------+
|                                                         |
|  +---------------------------------------------------+  |
|  |                                                   |  |
|  |               📁 영상 파일 드래그 & 드롭              |  |
|  |                                                   |  |
|  |             [ 파일 선택 (mp4, mov) 버튼 ]           |  |
|  |                                                   |  |
|  +---------------------------------------------------+  |
|                                                         |
|  [ 투구 정보 입력 (Optional) ]                           |
|  - 투수 이름/ID: [ 텍스트 입력 칸 ]                      |
|  - 구종 (Pitch Type): [ 드롭다운 (직구, 슬라이더...) ]      |
|  - 볼카운트 (Count): [ 드롭다운 (0-0, 0-2...) ]          |
|                                                         |
|                [ 🚀 AI 분석 시작 버튼 ]                  |
|                                                         |
+---------------------------------------------------------+
```
